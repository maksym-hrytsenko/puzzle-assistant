# Puzzle Assistant

An iOS app that helps a person assemble a large physical jigsaw puzzle (~4000 pieces) by suggesting probable locations for individual pieces on a reference image, along with a confidence level. It does not assemble the puzzle and does not guarantee correct placement — it narrows the search space and requires the user's visual confirmation.

## Status

Second iteration: the piece detection and matching methods validated on real photos with the
Python test bench (`tools/piece_matching/`, see `docs/adr/0004-piece-detection-and-matching.md`)
are implemented on-device, and the UI was rebuilt (Ukrainian).

- **Piece outlines:** Segment Anything 2.1 (Apple's Core ML conversion, "small"), prompted with a grid
  of points; masks are filtered by piece shape, size and background share. Missed pieces can be added
  with a tap, wrong ones removed with a tap.
- **Location search:** Metal compute shader — masked colour correlation in Lab with a colour penalty,
  4 upright rotations, scale from the piece-count grid, coarse-to-fine; probabilities are an
  uncalibrated heuristic.

## Core scenarios

- **New puzzle** — load the finished picture (photo of the box/poster or an image file); it is
  perspective-corrected automatically (can be rotated), then split into a grid by the piece count.
- **Find places** — photograph loose pieces; every found piece is outlined. Tap a piece to see where it
  belongs on the picture (one or more places, each with a probability and grid row/column); delete
  badly found pieces or add missed ones with a tap.
- **Assemble an area** — select an area of the picture (snapped to the grid), take one or more photos of
  loose pieces; every piece is checked and those that belong to the area are highlighted.
- **Progress** — mark pieces as placed.

## Build & run

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` and is not committed to git.

1. Install XcodeGen once: `brew install xcodegen`
2. Download the SAM 2.1 Core ML models (~94 MB, not in git): `./scripts/download_sam_models.sh`
3. Xcode 26 needs the Metal toolchain once: `xcodebuild -downloadComponent MetalToolchain`
4. Generate the project: `xcodegen generate`
3. Open `PuzzleAssistant.xcodeproj` in Xcode, select a simulator or your iPhone, and Run.

To install on a physical iPhone, open the project in Xcode, select the `PuzzleAssistant` target → Signing & Capabilities, and choose your own Apple ID as the team — that step needs your Apple ID and can't be done on your behalf.

From the command line:
```
xcodegen generate
xcodebuild -project PuzzleAssistant.xcodeproj -scheme PuzzleAssistant -destination 'platform=iOS Simulator,name=iPhone 17' build
xcodebuild -project PuzzleAssistant.xcodeproj -scheme PuzzleAssistant -destination 'platform=iOS Simulator,name=iPhone 17' test
```

## Honesty note

Matching a puzzle piece to its location on a reference image is a computer vision problem with real, fundamental limits — especially for low-detail regions (sky, water, plain textures). The app is designed to always show its confidence level and never claim certainty it doesn't have.
