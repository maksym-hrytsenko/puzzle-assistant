# Puzzle Assistant

An iOS app that helps a person assemble a large physical jigsaw puzzle (~4000 pieces) by suggesting probable locations for individual pieces on a reference image, along with a confidence level. It does not assemble the puzzle and does not guarantee correct placement — it narrows the search space and requires the user's visual confirmation.

## Status

First working MVP skeleton: builds, passes its (currently minimal) unit tests, installs and launches on the iOS Simulator, and implements all core screens and the on-device CV/matching pipeline end to end (reference map capture, piece capture + segmentation, feature-print matching, zone mode, progress tracking).

**What has been verified:** the project compiles cleanly (`xcodebuild build`), unit tests pass, and the app installs and launches correctly on the iOS Simulator (confirmed visually via screenshot — lands on the puzzle list, not a crash).

**What has NOT been verified, and can't be from this environment:** the iOS Simulator has no camera, so real photo capture, perspective correction, piece segmentation, and — most importantly — actual matching accuracy have never been exercised against real photos of a real puzzle. The matching confidence score is an explicitly uncalibrated heuristic (see `docs/adr/0003-known-limitations.md`). Treat this as a functional skeleton to test on a physical iPhone with a real puzzle, not as a validated product.

See `docs/adr/` for architecture decisions and known limitations.

## Core scenarios

- **Reference map creation** — photograph the puzzle box/reference image; the app detects its boundaries, corrects perspective, crops, and adjusts color/contrast/sharpness.
- **Piece recognition** — photograph loose pieces; the app segments them, accounts for rotation, and returns ranked candidate locations on the reference image with confidence scores.
- **Zone mode** — the user selects a region of the reference image; the app restricts matching to that region and honestly reports when no photographed piece appears to belong to it.
- **Progress tracking** — mark pieces as placed, review low-confidence matches, see per-zone completion and capture history.

## Build & run

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` and is not committed to git.

1. Install XcodeGen once: `brew install xcodegen`
2. Generate the project: `xcodegen generate`
3. Open `PuzzleAssistant.xcodeproj` in Xcode, select a simulator or your iPhone, and Run.

To install on a physical iPhone, open the project in Xcode, select the `PuzzleAssistant` target → Signing & Capabilities, and choose your own Apple ID as the team — that step needs your Apple ID and can't be done on your behalf.

From the command line:
```
xcodegen generate
xcodebuild -project PuzzleAssistant.xcodeproj -scheme PuzzleAssistant -destination 'platform=iOS Simulator,name=iPhone 17' build
xcodebuild -project PuzzleAssistant.xcodeproj -scheme PuzzleAssistant -destination 'platform=iOS Simulator,name=iPhone 17' test
```

## Honesty note

Matching a puzzle piece to its location on a reference image is a computer vision problem with real, fundamental limits — especially for low-detail regions (sky, water, plain textures). The app is designed to always show its confidence level and never claim certainty it doesn't have.
